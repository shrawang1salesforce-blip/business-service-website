# Veda Technology

A responsive, single-page business website for Veda Technology. It introduces the organisation, gives visitors a few ways to explore its programmes and services, and answers common first questions.

## Preview locally

Open `index.html` in a browser. The page uses plain HTML, CSS and JavaScript; there is no build step or package installation.

## Before publishing

- Add Veda Technology's verified contact details and a working enquiry route.
- Check programme names, service descriptions and current availability with Veda.
- The typefaces are loaded from Google Fonts. System fonts are used as fallbacks.
