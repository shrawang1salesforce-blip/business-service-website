# Veda Technology

A responsive, single-page Veda Technology site with an independent plum, lime and warm-paper visual identity. It covers the virtual internship tracks, IT services, certification, intern reviews, FAQs and contact details.

## Preview

Open `index.html` in a browser. The project uses plain HTML, CSS and JavaScript; there is no build step or package installation.

The Apply buttons link to Veda Technology's official application page. The interface uses a locally composed wordmark; headings use Google Fonts with system fallbacks. Track filters, mobile navigation, review controls and FAQ disclosures work without a framework.

## Keeping details current

Internship availability, dates and program details can change. Check the official site before publishing updates or relying on the information here.
